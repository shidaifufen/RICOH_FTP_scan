扫描直连 · 一键注册   v1.0
=====================================

一、怎么启动（重要）
------------------------------------
程序有两种打包，选一种：
  ① 单文件版：本目录的 扫描直连.exe 一个文件就够，拷到哪都能跑（启动慢 2~4 秒）。
  ② 文件夹版：文件夹版\ 里的 exe 必须和 _internal 文件夹放在一起，
     只拷 exe 会报 Failed to load Python DLL（依赖在 _internal 里）。

推荐启动方式（不会弹 SmartScreen）：
  在 Windows 资源管理器里双击  启动.bat

  ⚠ 千万不要用「AI 助手 / 自动化脚本 / 沙箱终端」去启动它：
    那种受限环境里托盘图标加不上、桌面目录写不进去、浏览器的页面进程也起不来。
    判断方法：打开 logs\env-report.txt，正常机器会写
    「写入测试 桌面\扫描: 可写」；如果全是「拒绝」，就是环境不对，换双击。

如果一定要双击 exe：
  1. 右键 扫描直连.exe → 属性 → 最下方勾选「解除锁定」→ 确定；
  2. 再双击，若出现「Windows 已保护你的电脑」，
     点「更多信息」→「仍要运行」。这只是因为程序没有买代码签名证书，
     不是病毒；公司内部工具可以让 IT 加白名单。

二、为什么之前会报 Could not create temporary directory!
------------------------------------
旧版本是 PyInstaller 的「单文件 exe」，每次启动都要把自己解包到
%TEMP% 临时目录；在你的机器上这一步被拦住了（SmartScreen / 杀软 /
临时目录策略都可能导致），所以启动失败。
现在换成「文件夹版」：启动时不再写临时目录，这个问题不会再出现，
启动也更快。

三、第一次使用
------------------------------------
1. 双击 启动.bat，程序窗口打开；
2. 打印机地址、管理员账号密码、保存目录已经预置好（config.json）；
3. 在「目的地名字」里填一个名字（比如 张三），点「确认并注册」；
4. 看到「注册完成」后，到打印机面板：扫描 → 选择「张三」→ 开始扫描，
   文件会直接进  桌面\扫描  文件夹。

四、运行后会看到
------------------------------------
- 右下角通知区域出现程序图标：悬停看状态，双击打开窗口，
  右键可以 启动/停止 FTP、复制地址、看状态、打开保存目录、退出。
- 点窗口右上角 × 只是收进托盘（FTP 继续接收）；
  要真正退出请用托盘右键菜单的「退出」。
- 日志文件：logs\app.log（出问题把这个发出来最快）
- 失败现场快照：logs\debug\（截图 + HTML）

五、出问题怎么办
------------------------------------
- 打印机连不上：确认本机与打印机在同一网络（能打开 http://打印机IP/）
- 提示「进入服务器的用户数超过最大允许限制」：等 1~2 分钟或重启打印机
- 注册失败：把 logs\debug\ 里最新的 .png 和 .html 发出来
